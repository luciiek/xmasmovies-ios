# XmasMovies — Holiday Movie Advent Calendar (iOS)

**XmasMovies** is a native iOS advent calendar app that unlocks a curated Christmas movie recommendation every day from December 1st to December 24th. Built with **Swift** and **SwiftUI** and published on the Apple App Store.

🔗 **HOPEFULLY SOON ON APP STORE (waiting for review)**

---

## Features & Technical Highlights

- **Daily Advent Unlock Logic:** Date-aware countdown and daily content unlocking mechanism for 24 curated holiday films.
- **Native SwiftUI Interface:** Custom festive cards, smooth transitions, and responsive layout built entirely in SwiftUI.
- **StoreKit 2 Integration:** Built-in optional Tip Jar supporting native In-App Purchases.
- **App Store Release Lifecycle:** End-to-end delivery including Xcode asset configuration, TestFlight testing, App Store Connect metadata, and Apple App Review compliance.
